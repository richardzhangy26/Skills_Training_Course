# 证据规则

## 证据归属

- 学生的回答、选择、操作和提交内容属于学生表现证据。
- 智能体的提问、提示和示范只属于任务上下文。
- 普通版聊天记录中，只有 `role=user` 的 `content` 属于学生证据。
- `role=assistant` 的表扬、评价、纠错和总结不等于学生已经达到相应水平，必须回到学生原话核验。
- 智能体替学生完成的内容不得计为学生能力。
- 教师要求和面试流程目标属于评价基准，不属于学生表现。

## 证据强度

优先使用可定位的直接证据：

1. 学生实际完成的关键操作或最终产出。
2. 学生在追问下给出的解释、判断和修正。
3. 测验、材料、语音或实操记录中的可验证内容。
4. 仅有次数、时长、字数或关键词的统计信息。

次数、时长和字数只能描述行为，不能单独证明能力水平。

## 公平性

- 只评价本次训练要求且系统实际采集的内容。
- 不依据性别、年龄、口音、外貌、设备质量等无关特征评分。
- 音视频质量不足时，只评价可靠转写或识别出的内容。
- 没有证据时降低判断置信度，不编造证据。
- 每个维度原因至少引用一条正向证据或问题证据。
