# 给接手 Agent 的入口

用户已在 Polymas 教师个人资源库的 AI 助教中装配专家团，希望根据功能验收原文完成测试并最多修复三轮。首先完整读取 [迭代执行说明](ITERATION_RUNBOOK.md)，然后查询已有状态；没有状态时才发现目标并初始化。

用户输入只有以下三类即可开始准备工作：

- AI 助教 `agentId`（此处指助教 app NID，不能拿单个专家 NID 替代）。
- 本地 `.env` 路径；只在当前机器读取，内容不进入聊天或代码。
- 功能验收原文，包括“用户怎么问／专家应该怎么做／最后得到什么”。

你负责读取实际专家和 Skill、取得源码、把验收原文拆为测试与准则，优先复用 [原子 Skill 目录](reference/atomic-skill-catalog.md)。目录 JSON 是由两份用户提供 Excel 整理的历史来源；挂载前必须核对平台当前精确标识、版本及角色权限。

最多3轮修复，初始测试不计入修复轮次。仅修改用户授权范围中的专家 `Agent.md` 和 Skill；涉及 AI 助教提示词，展示具体原因及差异并先与用户协商。不要降低验收标准，不把项目 `AGENTS.md` 当作专家提示词，不以增加轮次或重建状态绕过上限。

脚本返回 `next_action`。外层 Agent 完成对应步骤后，再调用下一个动作；无需依赖某个品牌模型。完成标准是脚本的真实测试链路、逐准则证据和实际部署回读全部满足。没有通用 Skill 源码回读接口、凭证失效、缺少专业病例或平台权限时，记录真实 `BLOCKED`；不要构造成功回执。

可直接交给下一 Agent 的任务描述：

> 阅读脚本包里的 team_acceptance/START_HERE.md 和 ITERATION_RUNBOOK.md。我的助教 ID 是〔填写〕，env 文件路径是〔填写本地路径〕。以下是验收原文：〔粘贴功能描述〕。只允许修改专家 Agent.md 和 Skill，助教提示词必须先与我协商。先复用原子 Skill 目录已有能力，初始基线后最多修复3轮；逐轮保存真实对话、修改差异和回读证据。已有状态目录是〔若存在则填写〕，优先继续该状态。达到固定验收后交付；条件不足或三轮未通过时如实报告，不改标准取得通过。

运行帮助：`python iterate_expert_team.py --help`。
