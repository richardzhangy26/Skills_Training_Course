# 功能1 规培生临床病例推理

本文件保存用户提供的验收原文，用于展示功能验收格式。它不是临床诊疗指南，也不是已完成线上测试的医疗专家配置。

- 用户怎么问：规培生 @妇产科规培专家，提交门诊、病房或急诊病例，询问“下一步应补充什么病史”“鉴别诊断如何排序”“应选择哪些检查”“当前最危险的问题是什么”。
- 专家应该怎么做：先确认训练场景和患者安全风险；按“问题表征→危险信号→鉴别诊断→检查选择→初步处置→上级汇报”逐步追问和引导。对异位妊娠破裂、产后出血、子痫、脓毒症等急危重症，优先提醒呼救、监护、启动本院急救流程和上级支持。除非学生明确要求，先不直接公布答案。
- 最后得到什么：一份结构化临床推理反馈，包括问题表征、诊断证据链、遗漏信息、检查优先级、风险提示、交班要点及个性化补强建议。

## 测试设计要求

外层 Agent 从上述原文拆解测试，使用与目标课程相符且已脱敏的教学案例材料。参考病例和专家 ID 未提供前不生成宣称可实跑的线上配置。

| 原文要求 | 应收集的对话证据 |
| --- | --- |
| 确认训练场景与安全风险 | 首轮提问/提醒，而非只在总结中提到安全 |
| 六步逐步追问引导 | 同一教学案例多轮对话的先后顺序及每步反馈 |
| 急危重症优先响应 | 在相应测试材料明确给出危险情景时，安全响应优先于常规教学流程 |
| 不提前公布答案 | 学习者未要求答案时的引导，以及明确要求答案后的响应，两类用例分别覆盖 |
| 完整结构化反馈 | 结束时的七项内容与原病例、学习者回答一致 |

医疗正确性不能用关键词命中代替。外层评价者应依据任务所提供的教学材料和适用的权威参考独立核对；缺少病例或依据时记录未验证。当前工程仅转录用户要求，没有补充新的诊疗建议。
