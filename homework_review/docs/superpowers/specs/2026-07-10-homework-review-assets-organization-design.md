# 批阅技能与素材分类整理设计

## 目标

把当前散落在 `homework_review` 根目录、`.qoder/skills`、独立技能目录和课程资料目录中的批阅技能与配套素材整理成一个可浏览、可追溯的分类入口，同时不破坏 Qoder 对正式技能的发现路径。

## 核心原则

1. 正式技能保留在 `.qoder/skills`，不改变 Qoder 的发现路径。
2. 可明确匹配的根目录批阅素材实际移动到新的分类目录。
3. 分类目录通过相对符号链接提供正式技能入口，避免复制和版本分叉。
4. 独立技能副本、ZIP 包和历史版本归入对应项目的交付包或历史版本目录。
5. 文件不能可靠匹配时进入 `99-待确认`，不根据模糊文件名强行归类。
6. 不移动作业批阅程序、通用测试程序、临时运行目录和与素材整理无关的工程文件。

## 目标目录

```text
批阅技能与素材/
├── README.md
├── 整理清单.tsv
├── 01-波形图与数字逻辑/
├── 02-图片识别与PPT/
├── 03-实验报告与综合文档/
├── 04-视频与动作/
├── 05-音频与口语/
├── 06-文字作业与试卷/
├── 07-通用技能与工具/
└── 99-待确认/
```

每个具体批阅项目按需要采用以下子目录；没有内容的子目录不创建：

```text
项目名称/
├── 技能入口/
├── 教师基准/
├── 学生样例/
├── 测试结果/
├── 交付包/
└── 历史版本/
```

## 初始分类映射

### 01-波形图与数字逻辑

- 通用波形图：`grade-waveform-homework`、`波形图作业批阅`及对应题目、标准答案和学生样例。
- 四题数字逻辑：`grade-digital-logic-four-questions`、独立技能副本、ZIP 包及四题数字逻辑教师基准。

### 02-图片识别与PPT

- 水生生物学藻类易混种：`grade-aquatic-algae-confusable-species`、教师 PPT/答案截图及学生答卷。
- 其他以图片识别或 PPT 为主要证据的素材，经内容核验后放入本类。

### 03-实验报告与综合文档

- 随机信号处理、植物地理学等实验报告：`实验报告批阅智能体`中的要求、评分细则、报告样例和批阅结果。
- 热重分析实验：`燃烧学-西安交通大学-作业批阅`中的实验材料、评分标准、学生样例和测试结果。
- 其他以实验报告、课程报告或多文档材料为主要提交物的项目。

### 04-视频与动作

- 通用动作视频：`grade-action-video-comparison`、独立技能副本、舞蹈标准视频、学生视频和片段测试材料。
- 外科操作视频：`grade-surgical-gown-glove-video`、皖南医科大学教师示范、评分表、学生视频和工作片段。
- 即梦文生视频：`grade-jimeng-text-to-video-homework`及南京职业技术学校对应课程资料和作品。
- 即梦图生视频：`grade-jimeng-image-to-video-heavy-equipment`及对应提示词、首尾帧和视频作品。
- 环保配音字幕：`grade-hailuo-bijian-eco-dubbing-subtitles`及对应课程 PDF 和音视频作品。
- 英语演讲、辩论/模联：以视频为主交付物，PPT、讲稿作为同一项目的教师基准或学生附件。

### 05-音频与口语

- 音乐表演：`grade-music-performance`及音乐参考音频、学生演唱或演奏样例。
- 外语发音：独立外语发音技能、ZIP 包、参考文本和学生朗读音频。
- 低碳生活 AI 配音：`grade-low-carbon-ai-voiceover`及对应任务要求和音频作品。

### 06-文字作业与试卷

- 通信原理单元测试一、二、三及统一入口技能，对应试卷、答案、评分要点和测试答卷。
- 离散数学证明题、日语日记、大学英语写作翻译、法律诊所等文档类技能与素材。
- 古代汉语、中医药学等已有批阅材料；若没有专用正式技能，保留“素材齐全、技能待补”的状态说明。

### 07-通用技能与工具

- `create-custom-homework-review-skill` 及其发布包。
- 仅建立入口和说明，不移动 `homework_reviewer_v2.py`、报告生成器、批量测试工具等工程代码。

## 匹配与迁移规则

1. 优先按技能名称、课程名称、作业题目、技能内引用文件名四类证据匹配。
2. 同一项目跨多种媒体时，以主要学生交付物确定主分类，在总目录中增加交叉索引，不复制大文件。
3. 正式技能目录使用相对符号链接；独立副本和 ZIP 包实际移动到项目目录。
4. 教师题目、标准答案、评分细则、标准示范归入 `教师基准`。
5. 学生原始提交归入 `学生样例`；由系统生成的评分、截图、日志和报告归入 `测试结果`。
6. 已打包的交付 ZIP 归入 `交付包`；明显的旧版、重复版归入 `历史版本`，不直接删除。
7. `tmp`、`output`、`document` 等运行目录只在能确定属于某一批阅项目且不是当前运行依赖时迁移；否则保持原位并在清单中记录。
8. 每次移动在 `整理清单.tsv` 中记录原路径、目标路径、动作、分类依据和状态，以便追踪或回退。

## 验收标准

1. 七个分类和 `99-待确认` 均有清晰索引，能从技能找到素材，也能从素材找到技能。
2. `.qoder/skills` 中现有正式技能数量不减少，所有分类技能入口均无断链。
3. 根目录中已匹配的课程素材不再散落；未匹配文件集中列入待确认清单。
4. 不覆盖同名文件、不删除非完全重复文件、不改动技能和素材内容。
5. `整理清单.tsv` 的源路径和目标路径完整，README 汇总技能、素材、缺失项和跨媒体关联。
6. 整理后运行路径检查、符号链接检查和技能清单核对，确认分类操作未破坏现有批阅能力。

## 非目标

- 本次不修改技能评分逻辑、提示词、脚本或评价结构。
- 本次不清理整个项目的所有临时文件和测试输出。
- 本次不为缺少专用技能的素材自动创建新技能。
