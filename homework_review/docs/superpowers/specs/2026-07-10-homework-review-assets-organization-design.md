# 批阅技能与素材分类整理设计

## 目标

把 `homework_review` 中的批阅技能与配套素材整理为可独立浏览的实体文件目录。分类目录不使用符号链接；正式技能、测试包和关联素材均复制为实体副本，同时保留其原始来源。

## 最终决策

1. `.qoder/skills` 中的 20 个正式技能保留原位，分类目录保存实体技能副本。
2. `.agents/skills/create-custom-homework-review-skill` 保留原位，分类目录保存实体副本。
3. `output/`、`test_bundles/` 保留原位；与具体项目匹配的内容复制到分类目录。
4. 不使用任何符号链接，包括技能入口、测试资料入口和根目录兼容入口。
5. 原 `03-实验报告与综合文档` 不保留。`实验报告批阅智能体`和`燃烧学-西安交通大学-作业批阅`恢复到项目根目录。
6. `舞蹈动作批阅`在根目录和分类目录各保留一份实体目录，兼顾原路径和分类浏览。
7. 不删除课程素材、正式技能、独立技能或历史版本；重复文件仍保留并标明来源。

```text
批阅技能与素材/

├── 整理清单.tsv
```

```text
项目名称/
├── 技能副本/
├── 教师基准/
├── 学生样例/
├── 测试结果/
├── 交付包/

```

- `create-custom-homework-review-skill` 实体副本和发布包。
- 核心批阅程序和报告生成程序仍保留在项目根目录，不复制到分类目录。

## 实体复制规则

1. 复制目录时保留文件名、目录层级、扩展名和文件内容。
2. 正式技能复制到 `技能副本/`，不再使用“技能入口”命名。
3. 跨类别资料只复制必要文件或项目测试包，不复制整个运行目录。
4. 同一个源目录需要保留原路径时使用实体目录副本，不使用兼容软链接。
5. 复制后对文件数量、总字节数或 SHA-256 进行核对；关键重复文件继续保留。
6. `整理清单.tsv` 使用 `移动`、`复制`、`恢复` 三种动作，不再记录 `链接` 或 `兼容链接`。
7. 分类目录中的技能是快照副本。后续若正式技能更新，需要按来源重新同步副本，README 中明确这一点。

## 原 03 分类的处理

1. 将 `实验报告批阅智能体`恢复到 `homework_review/实验报告批阅智能体`。
2. 将 `燃烧学-西安交通大学-作业批阅`恢复到 `homework_review/燃烧学-西安交通大学-作业批阅`。
3. 删除仅由本次整理生成的项目 README，避免把说明文件混入恢复后的原始素材；不删除原始课程文件。
4. 删除空的 `03-实验报告与综合文档` 目录。
5. 原 `04` 至 `07` 分类依次重编号为新的 `03` 至 `06`。

## 风险控制

- 在转换前记录全部软链接及其真实目标。
- 先复制到临时同级目录并核对，再移除软链接或重命名目录。
- 不覆盖已存在的实体文件；若目标同名，先比较内容再处理。
- 根目录恢复和分类重编号完成后，再更新 README 与迁移清单。
- 用户已有的 Git 未提交改动和核心代码文件不在本次修改范围内。

## 验收标准

1. `find 批阅技能与素材 -type l` 无输出。
2. `find homework_review -mindepth 1 -maxdepth 1 -type l` 无输出。
3. `批阅技能与素材/03-实验报告与综合文档` 不存在。
4. 根目录的 `实验报告批阅智能体`、`燃烧学-西安交通大学-作业批阅`和`舞蹈动作批阅`均为真实目录。
5. 新分类编号连续为 `01` 至 `06`，另有 `99-待确认`。
6. 20 个正式 Qoder 技能在 `.qoder/skills` 中保持不变，分类目录中存在 20 个可读取的实体技能副本。
7. 所有由软链接转换的目标均为普通文件或目录，关键复制内容通过数量、字节数或 SHA-256 核验。
8. README 与整理清单不再出现软链接、符号链接或兼容链接作为当前实现方式。

## 非目标

- 本次不修改技能评分逻辑、提示词、脚本或评价结构。
- 本次不修复与目录整理无关的既有项目测试断言。
- 本次不自动创建实验报告、中医、古代汉语或大学物理专用技能。
