# 穿手术衣视频批阅关键动作媒体对比设计

## 背景

`grade-surgical-gown-glove-video` 当前输出动作段对齐和证据路径，但老师在报告中无法像参考截图一样直接比较学生动作与标准动作。通用动作视频 Skill 已采用 `清单式 + items[].images[]` 展示关键差异素材，证明项目内已有可复用结构。

## 目标

- 在不改变 21 项、100 分评分表的前提下，新增精简的关键动作媒体对比。
- 每次只展示 2-4 个最影响得分或最需要复核的动作。
- 左侧展示学生动作细证据，右侧展示固定标准锚点图。
- 学生短视频片段作为附加证据；无法播放或无法生成时，细拼图必须仍可完成对比。
- 输入为老师标准视频且没有明确动作差异时，不得为了填充卡片而虚构差异。

## 非目标

- 不展示全部 12 个动作锚点。
- 不修改评分项、分值、无菌违规规则或口述项评分口径。
- 不新增标准视频片段包；本版标准侧复用现有锚点细拼图。
- 本设计阶段不自动同步或覆盖线上草稿。

## 方案

采用“图片对比优先，学生视频证据附带”的精简模式。

1. 完成学生动作锚点对齐和 21 项评分。
2. 从动作评分项中筛选实际扣分、明确无菌风险或高价值低置信度项。
3. 按扣分影响和教学价值排序，最多保留 4 项；同一动作的重复风险合并为一项。
4. 对每项截取学生对应动作片段，并从该片段生成 4-6 帧细拼图。
5. 标准侧使用 `reference.json` 中该锚点的 `standard_asset`。
6. 输出学生、标准两张图；学生短片路径写入 `evidence`，供支持视频播放的展示层使用。

## 输出结构

在 `evaluations` 中新增 `key_action_comparisons`：

```json
{
  "key_action_comparisons": {
    "format": "清单式",
    "items": [
      {
        "seq": 1,
        "title": "身体前倾使腰带悬垂",
        "standard_time": "00:35-00:53",
        "student_time": "00:42-00:58",
        "text": "标准要求；学生表现；明确差异；纠正方法。",
        "images": [
          {
            "label": "学生",
            "path": "work/key-comparisons/01-student.jpg",
            "caption": "学生对应动作的4-6帧细拼图"
          },
          {
            "label": "标准",
            "path": "references/surgical-gown-glove-v1/assets/anchors/gown_04_keep_belt_hanging.jpg",
            "caption": "固定标准锚点细拼图"
          }
        ],
        "evidence": "学生片段：work/key-comparisons/01-student.mp4；基于学生00:42-00:58与标准00:35-00:53同动作相位比较"
      }
    ]
  }
}
```

字段约束：

- `format` 固定为 `清单式`，复用项目内已有图文清单能力。
- `images` 必须恰好两项，顺序固定为学生、标准。
- `path` 必须是已存在的取证文件或内置参考素材，不得虚构 URL 或路径。
- `text` 必须说明标准要求、学生可见表现、明确差异和纠正动作。
- 仅因动作快、没有单独停顿或单帧不清晰，不足以生成差异卡；必须有同动作相位的正向差异证据。
- 没有明确动作差异时，`items` 输出空数组。

## Skill 调整

### 批阅流程

- 在学生细证据生成后增加“关键差异筛选与媒体对比”步骤。
- 学生片段建议控制在 2-8 秒；较长动作只截取最能说明差异的相位。
- 学生细拼图按片段时长均匀抽取 4-6 帧。
- 无法运行脚本、文件生成失败或路径不存在时，不得输出对应媒体字段；在证据摘要中说明降级原因。

### 评价项

- 保留综合评语、改进建议、动作段对齐、证据摘要和风险标记。
- 新增关键动作对比，展示顺序放在改进建议之后、动作段对齐之前。
- 删除对 `items[].images[]` 的全局禁令，改为只允许 `key_action_comparisons.items[].images[]` 使用媒体字段。

### 默认提示词

- 明确要求输出 2-4 个真实关键差异；没有明确差异则输出空数组。
- 明确学生/标准素材顺序和路径存在性要求。
- 强调不得把“看不清”直接写成动作错误或扣分差异。

## 降级策略

1. 学生视频片段生成成功、细拼图成功：输出两侧图片，并在 `evidence` 中附学生片段路径。
2. 片段成功、细拼图失败：不输出虚构图片，只保留文本差异和片段路径，并在证据摘要中标记降级。
3. 脚本不可用或平台不暴露生成文件：输出文本差异，不输出 `images`，并明确“媒体证据未生成”。
4. 标准锚点素材缺失：不生成该对比项，转入风险标记，避免无标准依据的单侧展示。

## 验收标准

- Skill 快速校验通过，脚本可编译。
- 输出仍只有 `score` 和 `evaluations` 两个顶层字段。
- `score.items` 仍为 21 项，总分等于分项得分之和。
- `key_action_comparisons.items` 数量为 0-4。
- 每个媒体对比项包含学生、标准两项图片，路径实际存在。
- 老师标准视频烟测不产生虚假动作差异卡。
- 有明确动作问题的测试视频能生成对应学生细拼图、标准锚点图和学生片段路径。
- 其他评价项格式及现有评分逻辑不回归。

## 风险

- 项目创建器文档仍把媒体字段标记为不可用，但通用动作视频 Skill 已使用该结构。实施后需要通过线上 preview 验证当前平台是否仍能渲染本地生成素材。
- 在线批阅环境此前未稳定展示脚本取证产物。即使 Skill 输出正确，平台若不上传运行时文件，报告可能只能显示文本；降级策略必须保留。
- 当前 `skill_draft_sync.py` 只适合文本文件同步，不能用于新增二进制标准片段，因此本版不增加标准视频片段包。
