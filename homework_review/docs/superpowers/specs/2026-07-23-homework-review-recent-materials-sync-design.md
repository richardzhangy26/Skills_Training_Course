2. 学生提交物统一保存到对应项目的 `学生作业/` 子目录。

4. 根 `README.md` 统一记录学生材料、后台 Skill 配置页、平台验证状态和能力边界。

## 后台链接规则

Skill 配置页统一使用以下格式：

```text
https://pds.polymas.com/im-capability-square/preview-skill?skillNid=<skillNid>&skillVersionId=<skillVersionId>&type=1&tab=skill&hiddenDetail=false
```

只有存在最终 `SUCCESS` 报告且能够确认 `taskId` 的场景，才增加报告链接：

```text
https://pds.polymas.com/im-capability-square/preview-skill/report?skillVersionId=<skillVersionId>&skillNid=<skillNid>&type=1&tab=skill&taskId=<taskId>
```

README 不把“配置页可打开”“execute 已返回”和“最终报告成功”合并为同一种状态。

## 重点能力边界

### 波形图与工程图

- 可稳定识别：清晰大字号标注、明显缺题、宏观结构和大面积波形差异。
- 有条件识别：逐信号区间、端口连接、交叉点、上下标和手绘局部错误；需要裁切、放大和结构化逐项核验。
- 当前不能可靠判断：低清小符号、密集连线拓扑、精确几何、公差和多视图空间一致性。
- 人工复核：任何扣分无法绑定具体题号、信号、时间区间或图中区域时。

### 动作与实验视频

- 可稳定识别：清晰可见的大阶段、明显顺序错误、完整缺段和明显违规。
- 有条件识别：精确次数、短暂停顿、小器械轨迹和表面接触；必须查看连续片段，不能依赖稀疏抽帧。
- 当前不能可靠判断：遮挡区动作、画面外准备、力度、温度、深度、真实污染和培养结果。
- 人工复核：低清、剪辑跳跃、镜头外操作、关键动作遮挡或只能凭前后状态推断。

### 演讲、销售与配音视频

- 可稳定识别：主要内容覆盖、明显跑题、可听清的表达结构和清晰字幕。
- 有条件识别：语气、停顿、互动效果、字幕同步和事实准确性；依赖音频转写质量与完整上下文。
- 当前不能可靠判断：无音频时的口述表现、被错误转写的专有名词、仅凭关键帧推断完整动态质量。
- 人工复核：平台预处理文本与原视频明显不一致、音频缺失或字幕遮挡严重。

### 口语音频

- 可稳定识别：是否可播放、目标句是否覆盖、整体可懂度和明显缺句。
- 有条件识别：流利度、整体语调和部分发音问题；依赖原始音频和可靠转写。
- 当前不能可靠判断：仅凭转写定位具体声母、韵母或四声错误。
- 人工复核：只有文本转写、音频噪声严重、多人重叠或模型给出没有声学证据的精细音系结论。

### 书面 DOCX

- 可稳定识别：可提取文本中的内容覆盖、词句错误、篇幅和结构。
- 有条件识别：扫描型 DOCX、手写图片、公式、上划线和复杂版式。
- 当前不能可靠判断：模糊手写、图片内微小符号和无法还原的版面关系。
- 人工复核：文档无可提取正文、嵌入图片未逐张打开或 OCR 与原图冲突。

## 复制和验证流程

1. 建立目标目录，不修改 `.qoder/skills` 正式 Skill。
2. 对每个源文件记录来源、目标、材料属性和平台状态。
3. 使用实体复制，不使用符号链接。
4. 同名目标存在时先比较 SHA-256；相同则跳过，不同则停止覆盖并记录冲突。
5. 复制后逐文件比较源文件与目标文件的大小和 SHA-256。
6. 更新 `整理清单.tsv`，记录本轮新增复制项。
7. 更新根 `README.md`，生成后台配置页和已确认的报告链接。
8. 检查所有 `学生作业/` 中没有教师示范、标准答案、评分标准或 Skill ZIP。
9. 检查 Markdown 相对路径存在，后台 URL 参数与本地配置一致。
10. 不删除原始材料，不修改现有大 ZIP，不推送或部署。

## 验收标准

1. 本设计列出的学生材料均在对应分类的 `学生作业/` 中存在。
2. 每个复制文件的源、目标大小和 SHA-256 一致。
3. 教师视频、教师基准、标准答案和评分表未混入新增 `学生作业/`。
4. README 中所有后台链接都包含已确认的 `skillNid` 和 `skillVersionId`。
5. README 对真实学生、课程样例和校准样本做了明确区分。
6. README 对波形图、视频、口语和扫描文档给出具体能力边界与人工复核条件。
7. 平台验证状态严格区分“已验证”“部分验证”“未逐份验证”。
8. `批阅技能与素材.zip` 保持不变。
9. 本次不修改任何 Skill 评分逻辑、平台草稿内容或现有测试结果。
