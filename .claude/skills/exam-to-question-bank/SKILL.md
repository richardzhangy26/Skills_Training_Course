# 试卷文档 → 题库整理

将试卷文档（Word / PDF / 纯文本）整理为题库系统可导入的格式：每道题按「题号 + 题干（含选项）+ 答案」排版，答案从文档末尾的答案区逐题配对回题目。

## 使用时机

- 用户提供试卷文档（.doc/.docx/.pdf），要求整理题目和答案用于题库导入
- 用户提到"题库"、"导入系统"、"题目+答案排版"等表述
- 典型触发："帮我把这份试卷的题目按题号和答案整理出来，方便导入题库"

## 核心原则

1. **忠实原文**：题干、选项、参考答案照搬原文，只修正明显的录入错误（错别字、全半角混用、"传人"→"传入"类 OCR 错误），不改写原意
2. **答案零丢失**：答案区的每个答案都必须落到对应题目上；题目区的每道题都必须有答案（缺失时补全并标注）
3. **标注透明**：凡是模型补全或修改过的答案，必须显式标注，禁止静默改动

## 工作流程

### 第 1 步：提取文本

```bash
python3 {skill_dir}/scripts/doc2text.py "<试卷文档路径>"
```

脚本输出 `<同名>.extracted.txt`，按格式自动选择提取器（Word 走 textutil/LibreOffice，PDF 走 pdftotext/PyMuPDF/pypdf）。

**PDF 扫描版（图片版）的特殊处理**：脚本提取结果为空或乱码时，说明 PDF 无文本层，改用 Read 工具直接读取 PDF（`pages` 参数分批读，每次最多 20 页），靠视觉识别题目与答案文本，跳过后续"读取 extracted.txt"步骤，直接进入第 2 步结构识别。

### 第 2 步：通读全文，绘制结构清单

用 Read 读取提取后的全文（超长文档分段读），先回答以下问题再动手：

- 有哪些题型？（问答/填空/名词解释/各类选择题）各多少题？
- 题目区在哪？**答案区在哪？**（常见三种：文档末尾集中答案、每题后跟答案、答案单独成节）
- 选择题的备选答案是全卷共用（B型配伍题）、分小组共用，还是每题独立？
- 是否有题号错乱、跳号、排版串行？记录在案

### 第 3 步：逐题型配对答案

按题型分节处理，**每处理完一个题型立即核对题数**：

1. 答案区该题型答案个数 = 题目区该题型题目个数？不等则先查明原因（跳号/串行/答案缺失），在产出中说明
2. 逐题配对：选择题配对答案字母；主观题配对完整答案文本
3. B型配伍题：先提取每组共用备选答案（注意原卷中选项可能被排版截断到多行，需先还原完整），再给组内各小题配答案字母

### 第 4 步：质量问题处理

逐一核查并处理（标注规范见 `references/output-format.md`）：

- **答案缺失**：依据学科标准知识补全，标注 `【补全】` 并附一句依据。拿不准的标注 `【存疑】` 而不是硬补
- **答案笔误**：如 "I3"→B、"C'"→C、小写字母、题号粘连（"6 2．"）等，直接修正
- **答案与题干矛盾**：保留原答案并标注 `【存疑】`，说明矛盾点
- **共用选项组不完整**：从上下文还原完整选项列表

### 第 5 步：按模板输出

严格按 `references/output-format.md` 的模板生成 Markdown：

- 文件名：`{源文件同名}-题库（含答案）.md`，保存在源文档同目录
- 文件头部必须写明：来源文件、【补全】标注说明、笔误修正清单
- 每个题型一节，标题含题数（如 `## 五、A1型选择题（96 题）`）

### 第 6 步（可选）：转 docx

用户要求 docx 时：

```bash
pandoc "<题库.md>" -o "<题库.docx>"
```

pandoc 不可用时提示安装（`brew install pandoc`），或直接交付 Markdown。

### 第 7 步：自检清单

交付前逐项确认：

- [ ] 每个题型的题数与答案数一致
- [ ] 全文无一道题缺答案
- [ ] 所有补全/存疑答案均已标注，且头部说明中列出
- [ ] 选择题选项完整（A–E 无缺漏），配伍题选项组完整
- [ ] 题干中无残留的排版串行内容（如上一题选项混入下一题题干）
- [ ] 向用户报告：题量统计、补全清单、存疑清单

## 常见陷阱

| 陷阱 | 应对 |
|------|------|
| 答案区题号与题目区不一致（跳号、串行） | 以题目区为准，按顺序位置对齐，差异在报告中说明 |
| 共用选项被排版截断跨行（如"E．上腹部、\n15．脐周围"） | 先还原完整选项组再配对 |
| 选择题答案字母与选项内容对不上（疑似原卷答案错误） | 保留原答案，标 `【存疑】` |
| 主观题答案中的表格被 textutil 拆成逐行文本 | 依据语义重建为 Markdown 表格 |
| 答案区混入题目区中间（非末尾集中） | 第 2 步结构清单必须确认答案位置，不能假设在末尾 |
| 文档过长一次读不完 | 分段读取；答案区与题目区分别定位行号后精读 |
| PDF 分栏排版导致左右栏文本交错 | pdftotext -layout 提取后若发现串行，改用 PyMuPDF 按块读取或直接 Read PDF 视觉识别 |
| PDF 页眉页脚/页码混入正文 | 配对时剔除重复出现的页眉页脚行（如"第 X 页 共 Y 页"） |
| PDF 中公式、特殊符号（离子式、希腊字母）被提取为乱码 | 依据上下文与学科常识还原，无法还原处标注 `【存疑】` |
