# 题库输出格式模板

生成的题库 Markdown 统一采用以下结构。所有题型遵循同一原则：**题号 + 题干在前，答案紧随其后，中间不插任何其他内容**。

## 文件整体结构

```markdown
# {章节/单元名} · 题库（题目 + 答案对照版）

> 说明：本题库由《{源文件名}》整理，每题紧跟对应答案，便于导入题库系统。
> 标注【补全】的答案为原答案区缺失、依据学科标准知识补充；其余均为原文参考答案。

---

## 一、{题型名}（{题数} 题）

{逐题内容，格式见下}
```

## 各题型排版格式

### 选择题（A1/A2/A3/A4 型，单选/多选）

每题一段，选项独占一行（或一行内用全角空格分隔），答案行固定为 `答案：X`：

```markdown
1．神经系统活动的基本方式是
A．反应　B．反射　C．效应　D．传导　E．反馈
答案：B
```

选项过长时拆为多行，保持 A–E 顺序完整。

### B型选择题（配伍题，共用备选答案）

共用备选答案无法拆散到单题，按"答案组 + 小题"块状排版，并在题型标题下加说明：

```markdown
## 四、B型选择题（配伍题，63 题）
> 说明：每组共用一组备选答案，请将该组备选答案与其后的各小题一并导入。

【备选答案组1】A．Na+、K+、Cl-　B．K+、Cl-　C．Na+　D．Ca2+　E．Cl-
1．在突触传递过程中，引起突触前膜释放递质的离子是
答案：D
2．……
答案：A
```

答案组的编号从 1 开始递增，组内小题保留原卷全局题号。

### 填空题

空格统一转为 `____`，多个空的答案用分号分隔，与空一一对应：

```markdown
3．兴奋性突触后电位是由于突触前神经元释放____递质，使后膜对____离子通透性增大……
答：兴奋性；Na+；去极；动作电位
```

### 名词解释

```markdown
1．突触
答：神经元之间相互接触并传递信息的部位，称突触。
```

### 问答/简答/论述题

```markdown
1．举例说明神经系统在机体功能活动调节中的作用如何?
答：{完整参考答案}
```

原答案含表格的（如比较表），转为 Markdown 表格嵌入答案。

## 答案质量标注约定

| 情况 | 处理 | 标注 |
|------|------|------|
| 答案区缺失该题答案 | 依据学科标准知识补全，答案后注明简短依据 | `答案：C【补全】（依据说明）` |
| 答案区有明显笔误（如 "I3"→B、"C'"→C、小写"c"） | 直接修正为标准字母 | 不标注，在文件头部说明中汇总 |
| 答案与题干明显矛盾（疑似原卷错误） | 保留原答案，加提示 | `答案：B【存疑】（矛盾说明）` |
| 主观题原文有错别字（"传人"→"传入"等） | 修正明显的 OCR/录入错误 | 不逐处标注 |

## 文件头部必含的说明要素

1. 来源文件名
2. 【补全】标注的含义
3. 本次修正的笔误清单（如有）
4. 缺失答案的题号及补全依据（如有）
