# 模型适配说明

## 统一模型：doubao-seed-2.0-pro

模型选择遵循[根目录统一规则](../../../../AGENTS.md#能力训练模型与数字人统一规则)。所有业务阶段显式填写 `doubao-seed-2.0-pro`；平台显示名称或模型 ID 不同时，通过当前模型接口核实映射。旧文档和脚本默认值不作为回退依据。

## 提示词设计与验证

- 指令保持简洁直接，避免复杂嵌套逻辑。
- 关卡判定条件使用明确的数字、要素和确认问题。
- 模拟人物明确“一问一答”和知识边界，避免主动透露未被询问的信息。
- 以当前任务的实际对话测试检验分支、跳转和信息边界，不沿用旧模型的主观效果比较作为验收依据。
