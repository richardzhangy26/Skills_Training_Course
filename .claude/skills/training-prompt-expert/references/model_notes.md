# 模型适配说明

## 推荐模型：Doubao-Seed-1.6

使用本skill生成的提示词，优先适配 `Doubao-Seed-1.6` 模型。

### 原因

- **听话度高**：seed 1.6 严格遵循提示词中的分支互斥、关卡锁定等复杂逻辑约束
- **不会过度发挥**：doubao 2.0 喜欢举一反三，容易曲解提示词意图；1.6 更忠实执行
- **模拟人物效果最佳**：在模拟病人等需要严格"问一答一"的场景中，1.6 不会主动透露多余信息

### 注意事项

- 其他非豆包模型对于模拟人物进行对话的效果较差，不建议使用
- 生成的提示词应保持指令简洁直接，避免过度复杂的嵌套逻辑（适配 1.6 的理解能力）
- 关卡判定条件要用明确的数字和关键词，不用模糊表述
