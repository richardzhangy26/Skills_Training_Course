# 红色绵州数智研习所剧本优化设计

**日期**：2026-07-28

**状态**：已确认

**采用方案**：四条独立路线、共享选择节点与总结节点

## 1. 背景与问题

现有 `训练剧本配置.md` 采用“1 个选择阶段 + 4 个共享场馆阶段 + 1 个总结阶段”的结构。四种游览顺序依赖同一批场馆节点根据历史对话回忆首选场馆，再从多条出边中选择下一场馆。

该实现存在两个需要优化的问题：

1. 正常讲解后的引导句经常直接给出下一问题，例如“想知道他后来领导了哪些革命斗争吗？”。参观者只需回答“想”“是”或照抄问题，不需要自主提炼线索和组织问题。
2. 共享场馆节点需要回忆首选场馆并判断下一站，平台拓扑不是“选择节点下挂四条独立纵向路线”，与确认的目标图不一致，也增加了历史判断错误和多出口连线维护成本。

## 2. 目标

1. 将场馆讲解引导调整为中等难度的自主探究：保留必要支持，但不把下一问题直接说出来。
2. 将平台拓扑改成一个场馆选择节点下挂四条独立路线。
3. 默认路线为 `1 → 2 → 3 → 4`；选择某一场馆时，该场馆排在第一位，其余场馆保持原始顺序。
4. 每条路线使用一个独立 Markdown 文件，路线中的场馆阶段均为独立节点。
5. 保留现有权威知识库、角色、讲解风格、背景图、数字人一致性和总结机制。
6. 所有跳转均使用唯一、中文、纯净的 `flowCondition`。

## 3. 非目标

- 不修改原始 DOCX 实训任务文档。
- 不扩写缺少权威来源的具体历史人物、日期、项目、灾情数字或技术参数。
- 不在本次工作中直接部署、覆盖或删除平台任务。
- 不改评价标准的四项评分框架和总分。
- 不把四条路线拆成四个独立训练任务。

## 4. 模块类型

### 4.1 场馆选择

类型：模拟人物型的路由变体。

小绵只介绍四个场馆的整体定位，识别参观者的首选场馆。参观者未明确选择、表示随意或请小绵安排时，进入默认路线。

### 4.2 四个场馆讲解

类型：模拟人物型。

参观者主动提问，小绵依据封闭知识库问一答一。四个场馆分别保持以下语气：

- 王右木真理拓源研习舱：庄重有温度。
- 三线建设耀绵州研习舱：厚重有力量。
- 两弹报国铸重器研习舱：沉稳崇敬、严谨有深度。
- 震后重生承大爱研习舱：沉稳克制、有共情。

### 4.3 游览总结

类型：总结型。

四条路线汇合到同一个总结节点。总结只回顾知识主题和精神内核，不虚构参观者的个人表现。

## 5. 拓扑设计

场馆编号：

1. 王右木真理拓源研习舱
2. 三线建设耀绵州研习舱
3. 两弹报国铸重器研习舱
4. 震后重生承大爱研习舱

四条路线：

| 选择 | 路线 |
|---|---|
| 未明确选择或选择场馆 1 | `1 → 2 → 3 → 4` |
| 选择场馆 2 | `2 → 1 → 3 → 4` |
| 选择场馆 3 | `3 → 1 → 2 → 4` |
| 选择场馆 4 | `4 → 1 → 2 → 3` |

整体结构：

```text
START
  ↓
场馆选择
  ├─ 路线1：1 → 2 → 3 → 4 ─┐
  ├─ 路线2：2 → 1 → 3 → 4 ─┤
  ├─ 路线3：3 → 1 → 2 → 4 ─┤→ 游览总结 → END
  └─ 路线4：4 → 1 → 2 → 3 ─┘
```

业务阶段总数为 18：

- 场馆选择：1 个。
- 四条路线：每条 4 个场馆阶段，共 16 个。
- 共享总结：1 个。

连线总数为 22：

- `START → 场馆选择`：1 条。
- `场馆选择 → 四条路线首站`：4 条。
- 四条路线内部：每条 3 条，共 12 条。
- 四条路线末站 → 共享总结：4 条。
- `共享总结 → END`：1 条。

## 6. 文件设计

保留并重写现有入口文件：

- `skills_training_course/绵阳职业技术学院-峥嵘绵阳/训练剧本配置.md`
  - 存放基础配置、场馆选择阶段、共享总结阶段、完整拓扑关系和装配说明。
  - 不再存放依赖历史回忆的共享场馆阶段。

新增四个路线文件：

- `训练剧本路线1-默认-1-2-3-4.md`
- `训练剧本路线2-2-1-3-4.md`
- `训练剧本路线3-3-1-2-4.md`
- `训练剧本路线4-4-1-2-3.md`

每个路线文件包含：

- 完整基础配置。
- 本路线的四个场馆阶段。
- 每个阶段的数字人、声音、形象、背景图、开场白、提示词和唯一跳转条件。
- 本路线的局部跳转关系。
- 路线编号和场馆顺序说明。

四个路线文件与入口文件共同构成一份逻辑完整的训练剧本包，不表示四个独立训练任务。

## 7. 阶段命名与跳转约定

同一场馆在不同路线中必须使用不同阶段名称。例如：

- `路线1-第1站-王右木真理拓源研习舱`
- `路线2-第2站-王右木真理拓源研习舱`
- `路线3-第2站-王右木真理拓源研习舱`
- `路线4-第2站-王右木真理拓源研习舱`

场馆选择节点输出的四个关键词：

- `进入路线1第1站王右木真理拓源研习舱阶段`
- `进入路线2第1站三线建设耀绵州研习舱阶段`
- `进入路线3第1站两弹报国铸重器研习舱阶段`
- `进入路线4第1站震后重生承大爱研习舱阶段`

路线内部跳转统一使用：

`进入路线N第M站完整场馆名称阶段`

四条路线进入共享总结时使用不同的纯中文关键词，防止同一任务内的 `flowCondition` 重复：

- `进入路线1完成后的游览总结阶段`
- `进入路线2完成后的游览总结阶段`
- `进入路线3完成后的游览总结阶段`
- `进入路线4完成后的游览总结阶段`

总结节点结束时仅输出：

`训练完成`

提示词分支、阶段字段、关系表和后续连线实现中的关键词必须逐字一致。

## 8. 自主探究难度设计

### 8.1 禁止的直接泄题话术

不再使用以下结构：

- “想知道他后来领导了哪些革命斗争吗？”
- “想了解灾后重建取得了哪些成果吗？”
- “想聊聊三线精神的具体内涵吗？”
- “要不要继续了解两弹一星元勋的故事？”

这些话术已经替参观者确定了下一问题的对象和内容。

### 8.2 正常回答后的默认引导

小绵先完整回答本轮问题，再邀请参观者根据刚获得的信息提出新的具体问题，但不提供候选问题或下一答案：

> 这条线索还能继续向下追查。请根据刚才的信息，提出一个你最想弄清楚的具体问题。

话术需要随上下文自然改写，不能每轮机械重复。

### 8.3 渐进式辅助

当参观者只说“想”“是”“继续讲”“还有吗”等内容时，不直接继续讲解，也不替其生成问题。

第一次无效提问：

> 请把你想了解的对象和角度说完整，我再为你讲解。

第二次仍无法提出问题：

> 你可以从人物、事件、原因、过程、影响或精神价值中选一个角度，再组织成一个具体问题。

辅助只能给出抽象思考维度，不能给出“王右木后来领导了哪些革命斗争”这类可直接照抄的问题。

### 8.4 有效提问判定

满足以下条件之一才视为有效提问：

- 包含明确对象和疑问角度。
- 能够从上一轮信息中提出因果、过程、影响、比较或价值层面的追问。
- 虽未使用问号，但语义上提出了可回答的具体信息需求。

以下内容不算有效提问：

- 单独的“是”“想”“可以”“继续”。
- 原样复述小绵刚给出的提示。
- 与场馆主题无关的闲聊。

### 8.5 开场白

开场白可以概括场馆的主要展陈范围，但结尾不直接给出若干现成问题。统一改为要求参观者选择一条线索并自行组织问题，例如：

> 请从刚才的介绍中选择一条你最感兴趣的线索，并用一个完整问题开始探索。

## 9. 内容一致性与事实边界

1. 四条路线中同一场馆的角色、知识库、事实边界、语气和有效提问规则必须一致。
2. 路线文件之间只允许以下差异：
   - 路线编号。
   - 阶段名称和站序。
   - 下一阶段名称。
   - `flowCondition`。
   - 路线局部关系表。
3. 王右木和两弹城知识库继续以现有权威简介文档为依据。
4. 三线建设和震后重生仍只使用原实训任务文档提供的主题框架，不补写未经提供的具体数字、人物或事件。
5. 小绵在全部阶段复用同一数字人配置；若当前平台资源可读取，实施时重新导出资源清单核对，不杜撰资源 ID。

## 10. 装配与连线

通用 `create_task_from_markdown.py` 只能按单个 Markdown 中的阶段顺序生成线性连接，不能直接把五个 Markdown 装配成一个选择节点下的四条独立路线。

实施阶段新增一个专用装配/连线脚本，职责限定为：

1. 读取入口文件和四个路线文件。
2. 校验路线顺序、阶段名称和跳转关键词。
3. 在 dry-run 中输出 18 个业务节点和 22 条连线的计划。
4. 支持平台状态只读回查。
5. 默认不得写平台；只有用户后续明确要求部署时才允许执行写操作。

脚本不得修改通用导入器的线性行为，也不得把四条路线合并回共享场馆节点。

## 11. 验收标准

### 11.1 Markdown 格式

- 入口文件和四个路线文件分别通过：

  `validate_markdown.py <文件> --strict`

- 提示词代码块内部不包含三反引号。
- 阶段编号在各文件内连续。
- 必需字段完整。

### 11.2 提示词质量

- 扫描不到“想知道……吗”“想了解……吗”“要不要继续了解……”等直接给出下一问题的话术。
- “是”“想”“继续”被判定为无效提问，不会自动触发下一段知识输出。
- 所有正常讲解分支执行“回答当前问题 → 邀请自主组织新问题”。
- 模糊问题辅助只给抽象维度，不给可照抄的具体问题。

### 11.3 路由

- 路线 1：`1 → 2 → 3 → 4`。
- 路线 2：`2 → 1 → 3 → 4`。
- 路线 3：`3 → 1 → 2 → 4`。
- 路线 4：`4 → 1 → 2 → 3`。
- 场馆选择未明确时只进入路线 1。
- 四条路线均只经过各自的四个独立场馆节点，途中不返回场馆选择节点。
- 四条路线末端均进入共享总结。
- dry-run 统计必须为 18 个业务节点、22 条连线。

### 11.4 边界

- 本地修改和验证完成后不自动部署。
- 不覆盖原始 DOCX。
- 不修改用户未授权的其他课程文件或现有未提交改动。
