# 冠心病中西医结合诊疗能力训练修改设计

## 目标

依据《7月24日智能体修改意见》，在不覆盖线上人工配置、不改变三选一路由结构的前提下，定点修改任务 `gbxP2ro08oh4L66KpaVQ` 的名称、节点文案、提示词、阶段顺序语义、总结输出和评价标准，并分别回归验证三个病例。

## 安全边界

- 修改前导出并保存当前任务的基础配置、全部步骤、流程边和评价标准。
- 以线上实际 Step ID 为唯一定位依据，不按 API 返回顺序与旧 Markdown 顺序批量配对。
- 不整体重新导入旧版三选一路由配置。
- 除本设计明确涉及的字段外，不改动现有数字人、音色、头像、背景和资源绑定。
- 先完成配置修改和预览验证，再决定是否需要新增专用过渡节点。

## 全局修改

1. 任务名称改为“冠心病的中西医结合诊疗模拟训练”。
2. 三个病例的治疗阶段统一命名为“中西医结合治疗方案”。
3. 三个病例的总结均先给出中西医结合诊断与治疗标准答案，再进行过程点评。
4. 总结输出采用 100 分制，包含总分和分项得分，不再只输出“优秀／良好／需改进”。
5. 评价标准改为三病例分支适配的统一量表，避免病例二、三被病例一专属答案误判。
6. 平台生成的“（AI生成）”标签不在任务配置中处理，单独记录为平台产品需求。

## 病例一修改

1. 初步诊断问题改为“西医与中医初步考虑什么诊断？”。
2. 体格检查中的“干湿啰音”改为“干湿性啰音”。
3. 辅助检查阶段先询问“患者需要做哪些辅助检查？”，学生作答后再展示结果。
4. “抓得不错”改为“分析合理”，“趁热打铁”改为“接下来”。
5. 辅助检查结果统一为：
   - CK-MB 18 U/L
   - 肌钙蛋白 I 0.02 ng/mL
   - 总胆固醇 7.5 mmol/L
   - 甘油三酯 3.3 mmol/L
   - 低密度脂蛋白 5.2 mmol/L
   - 高密度脂蛋白 0.6 mmol/L
6. 治疗阶段将中医治则、主方、具体药物组成设为独立必答项。
7. 西医治疗原则与具体药物设为独立必答项。
8. 删除会直接泄露诊断、治法、方药的正向示例和反馈复述；反馈只指出缺项，不代替学生作答。

## 病例二修改

1. 顺序采用“问诊→信息补充→体格检查→辅助检查规划与结果→诊断→治疗→总结”。
2. “信息补充”节点不提前询问辅助检查；体格检查完成后，在辅助检查节点先询问需要哪些检查。
3. 患者节点以自然患者口吻结束，不再朗读“进入信息补充”；下一年轻医生节点开场播报“下面进入信息补充”。
4. 辅助检查阶段删除直接给出诊断结论的示例和反馈，只允许提示遗漏的检查或解释维度。
5. 诊断阶段将中医病名、证型、辨证依据设为不可跳过的三个独立必答项，并仅依据学生最新回答判断是否完成。
6. 总结输出数字分数和分项得分，不输出单独等级作为最终结果。

## 病例三修改

1. “抓紧”改为“抓紧时间”。
2. 保留当前“完整体格检查结果位于第一次提问前”的结构，并进行回归验证。
3. 辅助检查结果在文本中补齐单位；同时上传一张复合检查报告图作为阶段资源。若平台预览不能在对话中稳定呈现，仍以带单位文本作为权威信息源。
4. 配对考试问题三改为：
   - 问题：为何急性心梗患者硝酸甘油含服无效？
   - 参考答案：心绞痛仅为冠脉狭窄、供血不足，血管未完全闭塞，硝酸甘油可扩张冠脉改善供血；急性心梗为冠脉完全血栓闭塞，硝酸甘油无法疏通闭塞血栓，故无效。
5. 中医治疗将治则、主方、药物组成设为独立必答项。
6. 西医治疗将治疗原则、具体药物设为独立必答项。

## 提示词行为约束

- 判断通过时只检查学生实际说出的内容，不用模型自己的前文补全学生答案。
- 一次只追问当前缺失项；学生未答时不得展示标准答案。
- 过程反馈只说明“分析合理”或指出缺失维度，不复述完整诊断与方案。
- 标准答案只允许在总结节点集中给出。
- 封闭式确认问题使用明确的“是／否”或编号回答，降低状态误跳转。

## 评价标准

维持 100 分制，统一为以下五项，并在每项内根据当前病例选择对应答案：

1. 问诊与危险信息采集：10 分。
2. 体格检查与辅助检查：20 分。
3. 西医诊断及依据：20 分。
4. 中医病名、证型与辨证依据：20 分。
5. 中西医结合治疗方案：30 分。

每个评分项必须记录扣分原因；总分等于五项得分之和。等级可作为附加说明，但不得替代数字分数。

## 验证与验收

1. 重新读取平台配置，逐项核对名称、节点名、提示词、流程边和评价标准。
2. 三个病例各运行一遍优秀学生路径，确认全部节点可达且不会提前泄露答案。
3. 病例二专项验证：
   - 信息补充由年轻医生播报；
   - 体格检查先于辅助检查规划；
   - 中医病名、证型、辨证依据缺一项时不得跳过。
4. 病例三专项验证：
   - 完整体检位于第一次提问前；
   - 检查结果单位完整；
   - 图片资源可见；
   - 硝酸甘油问题与参考答案完全一致。
5. 三个病例的最终输出均包含总分、五项分数、标准答案和过程点评。
6. 若任何流程边或资源呈现异常，使用修改前备份按 Step ID 恢复对应节点，不进行整任务覆盖。
